# 04 - URL and Query String Module

This lesson introduces Node.js URL parsing and query string helpers.

## Files

- `urlqs.js` demonstrates the `url` and `querystring` modules.
- `os.js`, `path.js`, and `fs.js` keep the earlier Node core module examples.

## What This Covers

- Importing Node's `url` module.
- Importing Node's `querystring` module.
- Parsing a URL with `url.parse()`.
- Formatting a URL from an object with `url.format()`.
- Parsing a query string into an object.
- Reading parsed query string values.
- Stringifying an object into a query string.

## Things To Notice

The lesson uses the older Node `url` and `querystring` core modules to show how URL parts and query parameters can be converted back and forth.
