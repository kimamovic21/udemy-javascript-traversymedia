# 01 - FS Module

This lesson introduces the Node.js `fs` module for working with files and folders from JavaScript.

## Files

- `fs.js` demonstrates file-system operations with `fs/promises`.

## What This Covers

- Importing Node's file-system module.
- Comparing callback, promise, sync, and async/await styles.
- Writing files with `writeFile()`.
- Reading files with `readFile()`.
- Deleting files with `unlink()`.
- Renaming files with `rename()`.
- Creating folders with `mkdir()`.
- Handling file-system errors with `try...catch`.

## Things To Notice

The active example calls `createFolder('folder1')`, so running the script from this lesson folder can create a new local folder.
