# 04 - ES Modules

This lesson introduces browser-based ES modules with `import` and `export`.

## Files

- `index.html` loads the app script as a module.
- `app.js` imports utilities and the `Person` class.
- `modules/utils.js` exports named helper functions.
- `modules/Person.js` exports a default `Person` class.

## What This Covers

- Loading JavaScript with `type="module"`.
- Importing named exports.
- Importing default exports.
- Exporting multiple helper functions.
- Exporting a class as the default value.
- Splitting app code into module files.

## Things To Notice

ES modules require explicit file paths in the browser, including the `.js` extension.
