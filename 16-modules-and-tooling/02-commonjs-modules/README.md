# 02 - CommonJS Modules

This lesson introduces CommonJS modules with `require()` and `module.exports`.

## Files

- `app.js` imports utilities and the `Person` class.
- `utils.js` exports helper functions.
- `Person.js` exports a `Person` class.

## What This Covers

- Importing modules with `require()`.
- Exporting multiple values from one file.
- Exporting a single class from a module.
- Destructuring imported helper functions.
- Calling imported functions.
- Creating an instance from an imported class.

## Things To Notice

CommonJS is the older Node module format. It uses `require()` to import and `module.exports` to expose values from a file.
