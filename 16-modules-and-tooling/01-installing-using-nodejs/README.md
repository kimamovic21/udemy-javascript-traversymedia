# 01 - Installing Using Node.js

This lesson introduces running JavaScript outside the browser with Node.js.

## Files

- `app.js` contains a simple async function that fetches GitHub user data and logs it in Node.

## What This Covers

- Running JavaScript with Node.js.
- Using `fetch()` in a Node script.
- Awaiting an HTTP response.
- Parsing JSON response data.
- Logging API data from the terminal.

## Things To Notice

This script is meant to be run with Node from the command line instead of opened in the browser.
