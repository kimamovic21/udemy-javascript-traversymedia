# 05 - Sets

This lesson introduces the `Set` data structure for storing unique values.

## Files

- `index.html` loads the set example in the browser.
- `script.js` demonstrates creating, updating, iterating, converting, and clearing a set.

## What This Covers

- Creating a `Set` from an array.
- Automatically removing duplicate values.
- Adding and deleting values.
- Checking membership with `has()`.
- Reading the set size.
- Converting between sets and arrays.
- Iterating through set values.
- Using the set values iterator directly.
- Clearing all set values.

## Things To Notice

Sets keep only unique values, so duplicate `2` and `3` values from the starting array appear only once in the set.
