# 08 - Stacks

This lesson builds a stack data structure with a JavaScript class.

## Files

- `index.html` loads the stack example in the browser.
- `script.js` defines a `Stack` class and demonstrates pushing, popping, peeking, checking length, and clearing.

## What This Covers

- Modeling last-in, first-out behavior.
- Creating a class-backed data structure.
- Adding items with `push()`.
- Removing the top item with `pop()`.
- Reading the top item with `peek()`.
- Checking whether the stack is empty.
- Tracking stack length.
- Clearing stack state.

## Things To Notice

The most recently pushed item is the first item returned by `pop()`, which is the key behavior that makes this a stack.
