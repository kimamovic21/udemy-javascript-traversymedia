# 06 - Maps

This lesson introduces the `Map` data structure for storing key-value pairs with flexible key types.

## Files

- `index.html` loads the map example in the browser.
- `script.js` demonstrates creating maps, setting values, reading values, checking keys, deleting entries, iterating, and converting to arrays.

## What This Covers

- Creating a `Map`.
- Adding entries with `set()`.
- Reading entries with `get()`.
- Using string and number keys.
- Checking map size and key membership.
- Deleting entries.
- Iterating with `forEach()`.
- Reading `keys()`, `values()`, and `entries()` iterators.
- Converting a map to an array.

## Things To Notice

Unlike plain objects, maps can use values such as numbers as keys without converting them into normal object property strings.
