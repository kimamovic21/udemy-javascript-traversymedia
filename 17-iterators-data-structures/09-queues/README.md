# 09 - Queues

This lesson builds a queue data structure with a JavaScript class.

## Files

- `index.html` loads the queue example in the browser.
- `script.js` defines a `Queue` class and demonstrates enqueueing, dequeueing, peeking, checking length, and checking whether the queue is empty.

## What This Covers

- Modeling first-in, first-out behavior.
- Adding items with `enqueue()`.
- Removing items with `dequeue()`.
- Reading the front item with `peek()`.
- Tracking queue length.
- Checking empty queue state.
- Shifting stored items after a dequeue.

## Things To Notice

The first item added is the first item removed, which is the main difference between a queue and the stack from the previous lesson.
