# 07 - Try Catch

This lesson introduces `try...catch` and shows how thrown errors can be handled without stopping the whole script.

## Files

- `index.html` loads the try/catch examples and includes `script.js`.
- `script.js` contains the error handling examples.

## What This Covers

- Wrapping risky code in a `try` block.
- Catching errors in a `catch` block.
- Throwing custom errors with `throw new Error()`.
- Validating function input.
- Checking numeric input with `isNaN()`.
- Logging caught errors.

## Things To Notice

The active example passes `'hello'` into `double()`, so the function throws a custom error instead of returning a number.
