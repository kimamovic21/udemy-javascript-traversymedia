# 03 - Fetch Options

This lesson shows how to send request options with `fetch()`, including method, body, and headers.

## Files

- `index.html` loads the fetch options page and includes `script.js`.
- `script.js` contains the POST request example.

## What This Covers

- Passing an options object as the second argument to `fetch()`.
- Sending a POST request.
- Converting request body data with `JSON.stringify()`.
- Setting request headers.
- Sending a `Content-Type` header for JSON.
- Reading the JSON response from a POST request.

## Things To Notice

JSONPlaceholder returns a simulated created post. It is useful for practice, but it does not permanently save the new data.
