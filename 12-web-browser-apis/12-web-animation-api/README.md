# 12 - Web Animation API

This lesson introduces the Web Animations API for creating and controlling animations from JavaScript.

## Files

- `index.html` contains the animated ball and control buttons.
- `script.js` contains the animation keyframes and controls.
- `style.css` styles the animation demo.

## What This Covers

- Defining animation keyframes in JavaScript.
- Setting animation timing options.
- Creating an animation with `.animate()`.
- Playing and pausing an animation.
- Reversing an animation.
- Changing animation speed with `playbackRate`.
- Running an animation infinitely.

## Things To Notice

The animation object returned by `.animate()` gives JavaScript direct control over playback, direction, and speed.
