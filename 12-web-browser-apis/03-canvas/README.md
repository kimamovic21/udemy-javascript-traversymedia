# 03 - Canvas

This lesson introduces the Canvas API for drawing shapes, text, lines, and images with JavaScript.

## Files

- `index.html` loads the canvas page and includes `script.js`.
- `script.js` contains the drawing examples.
- `ball.png` is used for the image drawing example.

## What This Covers

- Selecting a canvas element.
- Getting the 2D drawing context.
- Drawing filled rectangles.
- Drawing circles with `arc()`.
- Drawing lines with paths.
- Drawing filled and stroked text.
- Drawing an image onto the canvas.

## Things To Notice

The image is hidden in the page and drawn onto the canvas after it loads. Canvas drawing is immediate, so the script waits for the image `load` event.
