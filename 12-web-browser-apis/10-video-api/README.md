# 10 - Video API

This lesson introduces basic control of an HTML video element with JavaScript.

## Files

- `index.html` contains the video element and controls.
- `script.js` contains the video control logic.
- `media/` contains the video file and poster image.

## What This Covers

- Selecting a video element.
- Playing video with `.play()`.
- Pausing video with `.pause()`.
- Stopping video by resetting `currentTime`.
- Reading playback time during `timeupdate`.
- Updating the page with the current playback time.

## Things To Notice

The video API is very similar to the audio API because both use HTML media element methods and events.
