# 01 - Jest Setup

This lesson introduces the basic Jest setup for testing JavaScript functions in a Node project.

## Files

- `algo-testing/package.json` defines the project and the `npm test` script that runs Jest.
- `algo-testing/package-lock.json` locks the installed dependencies.
- `algo-testing/sum.js` exports a simple `sum()` function.
- `algo-testing/sum.test.js` tests that `sum(1, 2)` returns `3`.

## What This Covers

- Installing and running Jest.
- Adding a `test` script to `package.json`.
- Exporting a CommonJS function with `module.exports`.
- Importing code into a test file with `require()`.
- Writing a first Jest `test()` case.
- Using `expect()` and `toEqual()`.

## Things To Notice

The folder name is `01-jest-setp`, matching the current course files. The lesson content is a Jest setup example.
