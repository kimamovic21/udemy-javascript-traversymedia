# 03 - Reverse String

This lesson adds a reverse-string algorithm and tests its behavior with Jest.

## Files

- `algo-testiing/package.json` defines the Jest test script.
- `algo-testiing/sum/` and `algo-testiing/fizzbuzz/` keep the earlier examples.
- `algo-testiing/reversestring/reversestring.js` exports the `reverseString()` function.
- `algo-testiing/reversestring/reversestring.test.js` tests the reverse-string algorithm.

## What This Covers

- Reversing a string with `split()`, `reduce()`, and string concatenation.
- Keeping alternate solution ideas in comments.
- Testing that a function exists.
- Testing the return type.
- Testing multiple input and output pairs.
- Including strings with spaces in algorithm tests.

## Things To Notice

The nested folder is named `algo-testiing` in the current files. The README keeps that spelling so the paths match the project exactly.
