# 02 - Constructor Functions

This lesson introduces constructor functions as a way to create multiple similar objects.

## Files

- `index.html` loads the lesson page and includes `script.js`.
- `script.js` contains the constructor function examples.

## What This Covers

- Defining a constructor function.
- Using `this` inside a constructor.
- Creating instances with the `new` keyword.
- Adding instance properties and methods.
- Reading instance data.
- Checking an object's constructor.
- Checking instances with `instanceof`.

## Things To Notice

When `new` is used, JavaScript creates a new object, binds `this` to it, runs the constructor, and returns the new object.
