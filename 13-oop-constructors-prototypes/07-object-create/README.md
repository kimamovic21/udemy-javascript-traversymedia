# 07 - Object Create

This lesson introduces `Object.create()` as another way to build objects with a chosen prototype.

## Files

- `index.html` loads the lesson page and includes `script.js`.
- `script.js` contains the `Object.create()` examples.

## What This Covers

- Creating a shared prototype object.
- Defining reusable methods on that prototype object.
- Creating objects with `Object.create()`.
- Defining object properties with property descriptors.
- Calling inherited methods from created objects.
- Comparing square and non-square rectangles.

## Things To Notice

`Object.create()` lets you choose the prototype directly, without using a constructor function or the `new` keyword.
