# 01 - Object Literals This

This lesson introduces object literals with methods and shows how `this` refers to the current object.

## Files

- `index.html` loads the lesson page and includes `script.js`.
- `script.js` contains the object literal examples.

## What This Covers

- Creating object literals with properties.
- Adding methods to objects.
- Using `this` to access object properties.
- Calculating an area from width and height.
- Comparing two separate object literal instances.
- Seeing why repeated object literals can become repetitive.

## Things To Notice

Object literals are simple and useful for one-off objects, but creating many similar objects means repeating the same structure and methods.
