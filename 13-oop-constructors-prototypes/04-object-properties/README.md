# 04 - Object Properties

This lesson covers reading, adding, deleting, checking, and iterating through object properties.

## Files

- `index.html` loads the lesson page and includes `script.js`.
- `script.js` contains the object property examples.

## What This Covers

- Reading properties with dot notation.
- Reading properties with bracket notation.
- Adding new properties after object creation.
- Adding methods after object creation.
- Deleting properties with `delete`.
- Checking own properties with `hasOwnProperty()`.
- Reading keys, values, and entries.
- Iterating over entries with `for...of`.

## Things To Notice

`Object.entries()` gives key/value pairs, which makes it convenient to loop over an object's data and skip function values when needed.
