# 05 - Getters Setters Classes

This lesson uses class getters and setters to control how object properties are read and updated.

## Files

- `index.html` loads the lesson page and includes `script.js`.
- `script.js` contains the class getter and setter examples.

## What This Covers

- Creating backing properties with underscore names.
- Defining getters with `get`.
- Defining setters with `set`.
- Formatting values when they are read.
- Updating values through setters.
- Creating a computed `fullName` getter.
- Reusing helper methods inside getters and setters.

## Things To Notice

The public property names like `firstName` call getter and setter methods, while `_firstName` stores the internal value.
