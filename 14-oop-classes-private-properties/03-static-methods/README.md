# 03 - Static Methods

This lesson introduces static class methods that belong to the class itself instead of an instance.

## Files

- `index.html` loads the lesson page and includes `script.js`.
- `script.js` contains the static method example.

## What This Covers

- Defining a class with regular instance methods.
- Creating a static method with `static`.
- Calling an instance method from an object.
- Calling a static method from the class.
- Understanding the difference between instance and class-level behavior.

## Things To Notice

`area()` is called on `rect`, but `getClass()` is called on `Rectangle`. Static methods are not meant to be called from individual instances.
