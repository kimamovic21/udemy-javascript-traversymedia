# 01 - Classes

This lesson introduces JavaScript class syntax as a cleaner way to define constructor-style objects and shared methods.

## Files

- `index.html` loads the lesson page and includes `script.js`.
- `script.js` contains the class syntax examples.

## What This Covers

- Defining a class with the `class` keyword.
- Creating a constructor method.
- Setting instance properties.
- Adding methods inside a class body.
- Creating an instance with `new`.
- Calling class methods from an instance.
- Checking the created object in the console.

## Things To Notice

Class syntax is still built on JavaScript's prototype system. Methods like `area()` and `perimeter()` are shared through the class prototype rather than copied onto every instance.
