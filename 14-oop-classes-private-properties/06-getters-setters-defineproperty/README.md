# 06 - Getters Setters defineProperty

This lesson shows getter and setter patterns with `Object.defineProperty()` and object literal accessors.

## Files

- `index.html` loads the lesson page and includes `script.js`.
- `script.js` contains the `defineProperty()` and object literal accessor examples.

## What This Covers

- Creating getters and setters with `Object.defineProperty()`.
- Defining computed properties.
- Adding a prototype helper method.
- Reading capitalized first and last names.
- Creating a getter-only `fullName`.
- Defining getters and setters in an object literal.
- Creating an object from a prototype object with `Object.create()`.

## Things To Notice

`Object.defineProperty()` gives fine-grained control over properties, while object literal getters and setters provide a shorter syntax for the same basic idea.
