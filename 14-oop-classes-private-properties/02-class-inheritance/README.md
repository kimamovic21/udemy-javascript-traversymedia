# 02 - Class Inheritance

This lesson demonstrates class inheritance with `extends`, `super()`, and method overriding.

## Files

- `index.html` loads the lesson page and includes `script.js`.
- `script.js` contains the class inheritance examples.

## What This Covers

- Creating a parent `Shape` class.
- Creating subclasses with `extends`.
- Calling the parent constructor with `super()`.
- Adding subclass-specific properties.
- Inheriting parent methods.
- Overriding inherited methods.
- Checking inheritance with `instanceof`.

## Things To Notice

`Rectangle` inherits `logName()` from `Shape`, while `Circle` overrides it with its own version. That is a small example of polymorphism.
